# AE3200-DSE-Project-11
Official repository of Group 11 of DSE 2025-26

## Branches

- [Main branch](../../tree/main)
- [ROS](../../tree/ros_simulation) - Contains the code for the complete simulation of the UAV in ROS2.
- [Sensitivity Analysis](../../tree/Iterative_tools) - Contains the code to optimise the propulsion subsystem.
- [Budget](../../tree/budget) - Contains the code to estimate the volume, mass and cost budget of the UAV.
- [Sensitivity Analysis](../../tree/sensitivity_analysis) - Contains the code to do Monte Carlo sensitivity analysis on the trade-off criteria.
